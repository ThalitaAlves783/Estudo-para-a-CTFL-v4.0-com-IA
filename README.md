# Estudo para a CTFL v4.0 com IA

Material para quem está se preparando para a certificação **ISTQB® Certified Tester Foundation Level (CTFL) v4.0** e quer usar uma IA como tutora, com um painel para acompanhar a evolução.

Eu usei este método na minha preparação e fui aprovada em outubro de 2026:

| Momento | Resultado |
|---|---|
| Primeiro simulado completo | 26 de 40 (65%) |
| Simulado oficial A, uma semana depois | 36 de 40 (90%) |
| Simulado de curso, na véspera | 32 de 40 (80%) |
| Prova oficial | Aprovada ✅ |

## Começo rápido

1. Baixe este repositório: botão **Code → Download ZIP**, ou `git clone`.
2. Abra `dashboard/index.html` no navegador (dois cliques bastam, não precisa instalar nada).
3. Siga o [`COMO-CONFIGURAR.md`](COMO-CONFIGURAR.md) para preparar a IA com o prompt e os materiais oficiais.
4. Estude com a IA e registre cada questão no painel.

## Sobre o painel

- Calcula uma **nota estimada na prova**, ponderando cada capítulo pelo peso que ele tem no exame.
- Mostra **acertos por capítulo**, os **assuntos mais fracos**, a **evolução no tempo** e uma lista de **próxima revisão**.
- Aceita registros colados da IA: o prompt faz a IA terminar cada correção com uma linha como `#ctfl 4.2.2 erro`.
- Os dados ficam **só no seu navegador**. Use **Ver backup** para guardar uma cópia e **Restaurar backup** para levar para outro computador.

## Aviso

Material de estudo independente, sem vínculo com o ISTQB® ou o BSTQB. O syllabus, o glossário e os simulados oficiais pertencem a essas instituições e **não estão incluídos aqui**: baixe-os no site oficial do BSTQB.
